# KubeTee Brand Assets

This directory contains all official KubeTee brand assets including logos, icons, and brand guidelines.

## 📁 Directory Structure

```text
brand/
├── logos/              # Full logos (icon + text)
│   ├── svg/           # Vector logos (recommended for web)
│   ├── png/           # Raster logos (for documents/presentations)
│   ├── pdf/           # Vector logos (for print)
│   └── 4000x4000/     # High-resolution JPGs
│
├── icons/              # Icon only (no text)
│   ├── svg/           # Vector icons (recommended)
│   ├── png/           # Raster icons
│   ├── pdf/           # Vector icons (for print)
│   └── 4000x4000/     # High-resolution JPGs
│
└── downloads/
    └── KubeTEE.pdf    # Complete brand guidelines

```

## 🎨 Available Assets

### Logos (Icon + Text)

- **SVG**: 9 variations - Logo.svg, Logo-1.svg through Logo-8.svg
- **PNG**: 9 variations - Logo.png, Logo-1.png through Logo-8.png
- **PDF**: 9 variations - Logo.pdf, Logo-1.pdf through Logo-8.pdf
- **JPG**: 10 high-res (4000x4000px) variations

### Icons (Icon Only)

- **SVG**: 5 variations - Logo.svg, Logo-1.svg through Logo-4.svg
- **PNG**: 5 variations - Logo.png, Logo-1.png through Logo-4.png
- **PDF**: 5 variations - Logo.pdf, Logo-1.pdf through Logo-4.pdf
- **JPG**: 7 high-res (4000x4000px) variations

## 📖 Usage

All assets are publicly accessible via:

- Website: https://kubetee-ai.github.io/kubetee-website/brand
- Direct URLs: `https://kubetee-ai.github.io/kubetee-website/brand/[category]/[format]/[filename]`

### Examples

```text
https://kubetee-ai.github.io/kubetee-website/brand/logos/svg/Logo.svg
https://kubetee-ai.github.io/kubetee-website/brand/icons/png/Logo.png
https://kubetee-ai.github.io/kubetee-website/brand/downloads/KubeTEE.pdf
```

## ✅ Do's

- Use official assets from this directory
- Maintain logo proportions
- Use approved color variations
- Provide adequate clear space

## ❌ Don'ts

- Don't modify colors or proportions
- Don't add effects or distortions
- Don't rotate or skew logos
- Don't use on busy backgrounds
